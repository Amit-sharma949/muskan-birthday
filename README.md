# Muskan Birthday Website

## Preview
Open `index.html` in a browser. Keep the `images` folder beside it.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example `muskan-birthday`).
2. Upload `index.html` and the complete `images` folder (not just the HTML file).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a minute or two. GitHub will show your website URL in the Pages section.

The site is mobile-friendly and includes an animated birthday surprise and a playful party button.
